# HOTEL MANAGMENT SYSTEM

A full-stack application with a **Spring Boot backend**, **React frontend**, and dedicated documentation for backend APIs and sample data.

## 📁 Project Structure

```text
project-root/
│
├── backend/
│   └── Spring Boot application
│
├── frontend/
│   └── React application
│
├── docs/
│   ├── Backend APIs
│   └── API usage & sample data
│
└── README.md
```

## 🛠️ Technology Stack

### Backend

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- REST APIs
- Database integration

#### RUN BACKEND USING THIS COMMAND

```
mvn spring-boot:run
```

### Frontend

- React
- JavaScript / TypeScript
- React Router
- API integration with the Spring Boot backend

#### RUN FRONTEND USING THIS COMMAND

```
npm run dev
```

### Documentation

The `docs` folder contains:

- Backend API documentation
- API endpoints
- Request and response formats
- Sample request data
- Sample response data
- API usage examples
